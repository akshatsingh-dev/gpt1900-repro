1The question

Can an AI restricted to knowledge that existed before a breakthrough reconstruct the reasoning behind it, rather than retrieve it? GPT-1900, a 3.29B-parameter model trained only on pre-1900 text, was scored 0.93 out of 5 on eight physics reasoning prompts by an LLM judge, and nobody had checked whether that number could be reproduced. My job was the evidence layer: run it again, record everything that produced each answer, measure how much of the score belongs to the prompt and the grader rather than the model, and leave a record another researcher can check.

8Overleaf quickstart

For someone who has never opened Overleaf. Facts checked on the Overleaf site and the REVTeX 4.2 author guide on 7 Oct 2026; the pages are listed at the end.

  1. Make a free account. Go to overleaf.com and register. The free plan has unlimited projects, one collaborator per project, the basic compile timeout, and project history for the previous 24 hours only.
  2. New project. On the dashboard click New project, above the project list. The menu offers a blank project, an example project, Existing project (.zip), and templates.
  3. Pick one of two starts.
    • If Keating shares an Overleaf link or invites you by email, open it: you are a collaborator in his project and you do not create your own. If he sends a .tex or a .zip instead, choose Existing project (.zip) and drag the zip in. The main document must not sit inside a folder in the zip, and after it opens, check that the right .tex file is set as the main document.
    • Otherwise start from the APS template. In the template gallery search "RevTeX 4.2" or "APS". On 7 Oct 2026 the gallery shows two by the American Physical Society: RevTeX 4.2 Template and Sample (opens with \documentclass[reprint, amsmath, amssymb, aps]{revtex4-2}) and APS Physical Review Journals Template (opens with \documentclass[preprint, linenumbers, amsmath, amssymb, aps, physrev]{revtex4-2}). Names change; verify on the site. Click Open as Template.
  4. main.tex and the documentclass line. The first line of main.tex chooses the look. For a PRX-style manuscript: 
    \documentclass[aps,prx,preprint,superscriptaddress,amsmath,amssymb]{revtex4-2}
    From the author guide: aps is the default society option; prx is the Physical Review X journal option, new in 4.2 (physrev is the unified Physical Review style); preprint is single column for drafts and reprint is "an approximation to the selected journal's actual layout"; superscriptaddress links authors to affiliations with superscript numbers, where the default groupedaddress groups authors under their affiliation; linenumbers adds line numbers for reviewers. Draft in preprint, switch to reprint to see the journal look. REVTeX 4.2 needs natbib 8.31a or later, which Overleaf has. Which options Keating wants for the actual submission is his call; check with him.
  5. Where figures go. The upload icon is in the upper left of the editor; the folder icon next to it creates a folder. Make one called figures, upload PDF or PNG files into it, then in the preamble \usepackage{graphicx} (the templates already have it) and \graphicspath{ {./figures/} }. A figure is then: 
    \begin{figure}
  \includegraphics[width=\columnwidth]{sweep}
  \caption{\label{fig:sweep} Mean score per checkpoint under each grader.}
\end{figure}
    REVTeX numbers the captions FIG. 1, FIG. 2 and \ref{fig:sweep} cross-references them. The file name goes in without its extension.
  6. References via a .bib file. Create refs.bib in the project (the new-file icon, upper left). One entry per source, for example @article{hla2025gpt1900, ...}; cite in the text with \cite{hla2025gpt1900}; put \bibliography{refs} just before \end{document}. The journal option picks the bibliography style for you: apsrev4-2.bst for every APS journal except RMP, so no \bibliographystyle line is needed. Every source in reports/evidence-table.md becomes one entry.
  7. Recompile and the log. Press Recompile to build the PDF; the dropdown beneath it has auto-compile. The Logs and output files icon sits to the right of the Recompile button. Errors are red and stop the PDF; warnings are light orange and can usually be ignored; overfull and underfull box warnings are blue. Turn on Stop on First Error in that same dropdown so one mistake does not become fifty. After adding references, recompile again so the citations resolve; a question mark in the PDF means a key is missing from the .bib file.
  8. Sharing by link. The Share button is at the top right. Turn on link sharing gives a view link and an edit link; the edit link requires the other person to have an Overleaf account. Or invite by email with view-only, review, or edit permission. On the free plan "adding more than one collaborator per project (editor or reviewer) is a premium feature", so if you own the project you can add Keating and nobody else; if he owns it, his plan sets the limit.
  9. What needs a paid plan (plans page, 7 Oct 2026): track changes, Git and GitHub sync, Dropbox sync, full document history (free keeps 24 hours), the extended compile timeout, the symbol palette, and advanced reference search. A paying owner's collaborators get full history and extended compile time inside that project. Some universities hold a site licence; check whether UCSD does before paying. That was not checked.
  10. The habit: one section at a time. Paste one section from reports/paper-full-draft.md (if that file is not there yet, reports/paper-draft.md is the one with the numbers filled in), recompile, fix anything red, then paste the next. Markdown is not LaTeX: # headings become \section{}, **bold** becomes \textbf{}, tables become tabular, and %, & and _ must be escaped. Put the E-number beside every number as a LaTeX comment, % E042, so the paper stays traceable to the notebook.
