# Reports

`week-NN.md` is the written update sent to Prof. Keating on Monday night,
ahead of the Tuesday 1pm PT Zoom.

Each report is compiled from `notes/lab-notebook.md`, not written from memory.
Every claim in a report cites the notebook entry it came from, so any statement
can be traced to a command, a raw log and an exit status.

Rules carried over from the working agreement:

- Report negative results as prominently as positive ones.
- Always give denominators. "2 of 24" not "some".
- Nothing appears in a report that was not personally re-run and verified.
- Underpromise. If a phase slipped, the report says it slipped and why.
